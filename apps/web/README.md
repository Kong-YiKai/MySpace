# Web Application

住宅看房与 AI 装修模拟器的可运行前端。它把户型选择、毛坯房预览、装修需求生成、局部材质编辑和第一人称看房组织为一条不会跳页的状态流。

## 当前实现

- React + TypeScript + Vite。
- React Three Fiber 渲染毛坯房和精装房原型。
- 客户端户型图预检，拒绝格式错误或缺少平面结构特征的图片。
- Fake Provider 式生成进度，用于先验证产品状态与交互连续性。
- 可选墙纸、可点选家具、低饱和度颜色修改、第一人称 WASD 漫游。

## 边界

- Web 只通过版本化 API、状态流和受控资产 URL 接入后端。
- 户型识别与真实 3D 生成最终由 API/Worker 完成，前端启发式校验只是快速反馈。
- 手势识别通过独立计算服务输出高层输入事件，不把视觉模型耦合进渲染器。
